## Задание №1



### Алгоритм решения


#### 1) Объявляются переменные m,n являющиеся целыми константами. Они нужны для задания размера матрицы.
#### 2) Создаётся вещественна матрица размером m, n `float mtx[m,n];`
#### 3) Создаётся функция потока `CreateRow()`
```
DWORD WINAPI CreateRow(LPVOID param)
DWORD - тип возвращаемого значения функции.
WINAPI - соглашение о вызове функции, используемое Windows API
CreateRow() - название функции
LPVOID param - параметр который передаётся в поток при его создании.
каждый созданный поток будет выполнять эту функцию и заполнять одну строку матрицы.
```
#### 4) Получает значение параметра `int* prow = (int*)param;` и берёт значение по адресу `int row = *prow;`
#### 5) Выводится номер строки которая получена потоком. Нужна для проверки программы. 
#### 6) Для потока задаётся начальное значение генератора случайных чисел. `srand(GetCurrentThreadId());` после выводится идентификатор текущего потока `cout << "Идентификатор текущего потока: " << GetCurrentThreadId() << endl;`
#### 7) Поток заполняет 1 строку матрицы случайными числами от 0 до 99. И полученное значение преобразует к типу float.
#### 8) В функции `main()` создаются массивы для работы с потоками
```
HANDLE hThread[m];  - хранит дескрипторы созданных потоко.
DWORD dwThread[m];  - хранит идентификаторы потоков.
```
#### 9) Создаётся массив номеров строк `int row_numbers[m];` - в нём хранятся номера строк, которые будут передаваться потокам.
#### 10) Создаются потоки в цикле for, выполнятеся m раз (сколько всего строк)
#### 11) Вызывается CreateTheard()
```
NULL,			// Параметр безопасности по умолчанию
0,				// Размер стека по умолчанию
CreateRow,		// Имя функции, которая выполняет новый поток
&(row_numbers[i]),	// Указатель на параметры (передаёт адрес ячейки памяти в param)
0,				// Поток запускается сразу после создания
&dwThreadID[i]	// Адрес переменной для идентификатора
```

#### 12) Ожидание завершения всех потоков
```
WaitForMultipleObjects(
	m,			// Кол-во потоков для ожидания
	hThread,	// Указатель на массив указателей потоков
	true,		// Флаг ожидания. Показывает - нужно ли дождаться завершения всех потоков
	INFINITE	// Время ожидания завершения в миллисекундах (без огр по времени)
);
```

#### 13) Выводится матрица с помощью циклов for
#### 14) Закрытие дескрипторов потоков
```
for (int i = 0; i < m; i++)
{
	CloseHandle(hThread[i]);
}
```
